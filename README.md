# OpenPolimi

Course notes, transcripts, slides and assignments for ChatGPT and Claude.
[Available courses and latest lessons](COURSES.md).

**MCP URL:** `https://kb.openpolimi.ai/mcp`

## Get a token

1. Open [openpolimi.ai](https://openpolimi.ai).
2. Enter your `@mail.polimi.it` email and select **Continue**.
3. Enter or paste the six-digit email code, then select **Confirm code**.
4. Copy and save your token. It is shown once and has no expiry.

Creating a new token revokes your previous tokens and their connected assistants.
Connecting another assistant with your existing token keeps your other connections active.

## ChatGPT

1. In ChatGPT, open **Plugins → + → Add custom MCP server**.
2. Enter **OpenPolimi** and the MCP URL above. Choose **OAuth** with automatic client registration.
3. Create the connection. On the OpenPolimi page, paste your token and select **Allow**.
4. Select OpenPolimi in a new conversation.

Custom MCP access depends on your account and workspace settings.
[ChatGPT setup](https://developers.openai.com/plugins/deploy/connect-chatgpt).

## Claude

1. Open **Customize → Connectors → Add custom connector**.
2. Enter **OpenPolimi** and the MCP URL above.
3. Choose **Sign in now** and **Register automatically**.
4. On the OpenPolimi page, paste your token and select **Allow**.
5. Enable OpenPolimi in the conversation.

[Claude setup](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).
